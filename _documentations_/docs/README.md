Prototype $0; first live batch ≈ $30–50/batch-month (Supabase Pro $25/mo; LLM cost depends on the configured provider).

## v1.3 decisions (approved by Moza 2026-11-18)

1. **Certificate-name rule (D6, decided; closes OQ-06):** the KTP is the authority — the certificate name is the KTP name verbatim, word for word. Surat tugas, APL.01, and ijazah are compared against the KTP; any discrepancy resolves to the KTP spelling. Worked example: surat tugas "Declan Rice P." vs KTP "Declan Rice Pangabean" → final name "Declan Rice Pangabean". The jury's mismatch-resolved proposal is always the KTP spelling; abbreviations are expanded from the KTP only. The verdict still becomes the certificate name only after assessor confirmation or override; needs-human when the KTP itself is unclear/low-confidence.
2. **Pass-mark shape (D7 refined):** judging shape follows the reference Test Grader app — per-question verdicts Benar / Sebagian / Salah with Bahasa Indonesia explanations + per-student error summary ("Ringkasan Kesalahan"); plagiarism analysis is a separate qualitative report (Bersih / Waspada + reasoning), never a numeric verdict; no overall % shown as the decision. Roll-up default (v1.3, pending LSP confirmation): per-unit K/BK is the assessor's judgement per KUK over the per-question verdicts, with no numeric pass mark. OQ-04 stays open on the roll-up only.
3. **06B password + key structure (D12; OQ-14 answered in part):** each scheme's 06B ships with a PASSWORD Excel file holding the key password; the holder is the assessor, who supplies it at runtime (key-upload step) — never stored, never logged, never recorded anywhere. ## Canonical rules (do not break)

1. DIT = Daftar Instruksi **Terstruktur** (not "Tertulis").
2. Official FR.IA.04B (presentation assessment) ≠ the 13-question bank — separate artefacts; count is the scheme's manifest value (13 is AK3U's value — D17).
3. Decision is binary **K / BK** only — no "Kompeten Bersyarat" as a decision value, a status, or a recommendation (D15, v1.4; scheme §9.3.4 and the 04B form only offer Kompeten / Belum Kompeten).
4. FR.AK.05 is per-assessor, per-batch, a **recommendation** to TUK/LSP — not the certification decision (pleno decides).
5. AI recommends; the assessor decides (professional judgement, explicit on FR.IA.06). Similarity is a **flag**, never auto-fail.
6. Certificate name is **AI-jury adjudicated, human-confirmed; the KTP is the authority (D6)** — the jury compares APL.01 vs surat tugas vs ijazah against the KTP (OCR text); a mismatch-resolved verdict always proposes the KTP spelling. The certificate name is the KTP name verbatim, word for word. The jury verdict becomes the certificate name only after assessor confirmation; never auto-merged, never silently finalised.
